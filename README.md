# Google Form Auto Answer

A lightweight browser console script that automatically fills multiple choice, linear scale, and checkbox questions on Google Forms.

## How to use

1. Open any Google Form
2. Press `F12` → go to the **Console** tab
3. Paste the script and press Enter
4. Click **Start Auto-Answer**
5. Review the answers, then submit

## Features

- Works with Multiple Choice questions
- Works with Linear Scale (1–5, etc.)
- Works with Checkboxes (randomly selects 2–3 options)
- Floating control panel
- No login / email required
- No extension needed

## Notes

- Answers are chosen randomly
- Always review before submitting
- Google may change their form structure in the future
